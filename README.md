# AI & Agent coding study

Two pages, no account needed. Results go to the study's collector on Submit; if it cannot
be reached, the page shows your answers to copy and send instead.

* `index.html` - the **pre-test**: read two definitions, answer three checks, code 20
  products, give feedback (about 25 minutes).
* `study/index.html` - the **full study**: the same instructions, all 108 products.
  Progress is saved in your browser, so you can close the page and continue later.

Open the GitHub Pages URL for this repository, or the files directly.
